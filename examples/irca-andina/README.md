# Synthetic Andean water-quality exercise

`irca_andina_dataset.csv` contains 5,000 **synthetic** rows generated by
`generate.py` with fixed NumPy and Python random seeds. Each row is an invented
sample assigned an invented location in Boyacá, Cundinamarca, or Santander.
The locations do not encode measured regional differences. Run
`.conda/bin/python examples/irca-andina/generate.py` from the repository root
to reproduce the CSV.

The same CSV is available in a [public GitHub Gist](https://gist.github.com/project-delphi/e6afb121c1f7dc0d15531494f86bd408).
Its [versioned Raw URL](https://gist.githubusercontent.com/project-delphi/e6afb121c1f7dc0d15531494f86bd408/raw/5c7bbf97663a249dbd4c159992057b528ccd4eca/irca_andina_dataset.csv)
offers a separate download. The optional slide module renders from the bundled
CSV, so its computation does not depend on network access.

The columns use water-quality parameter names, but `irca_score` is the
exercise's arbitrary continuous formula with noise. It is **not an official
IRCA measurement or calculation**. `irca_clasificacion` applies the category
cutoffs to that synthetic score and is likewise an exercise label. Under
[Colombia's Resolution 2115 of 2007](https://normas.cra.gov.co/gestor/docs/resolucion_minproteccion_2115_2007.htm),
official IRCA uses weighted points for unacceptable measured characteristics,
including microbiological characteristics and other chemical measurements.
The regulatory categories use 0–5, 5.1–14, 14.1–35, 35.1–80, and 80.1–100%.
Regulation and formula checked 2026-10-28.

A model fitted to these rows only learns patterns in the generator. An 80/20
random split tests agreement on more rows from the same generator; it cannot
establish performance for real water, a municipality, a future date, or a
microbiological result. Because the generator uses coliforms to produce labels
but the teaching model omits that variable, the model cannot recover all of
the label information. Sensor readings can support an operational alert, but
they do not replace laboratory tests or official IRCA assessment.
