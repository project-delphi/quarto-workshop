El método

Un ciclo, en cada paso

Tú pides, tú revisas, Quarto reconstruye. Cada paso práctico del libro da una vuelta a este ciclo, así que un error se detecta mientras todavía es pequeño.

  1. Pide

    Describe una pequeña tarea para un agente de programación, con sus archivos y columnas por su nombre.

  2. Revisa

    Lee lo que cambió, mira el resultado, compáralo con los datos. Un agente puede ser elocuente, rápido y estar equivocado, así que este paso nunca se salta, y siempre te toca a ti.

  3. Publica

    Quarto reconstruye cada salida desde la fuente revisada, siempre de la misma manera.

Esta página se construyó como enseña el libro

Esta página es un documento de Quarto. Cuando se construye, el código lee los datos, la lista de capítulos y la cubierta del libro, así que cada número que aparece en ella, el contenido de más abajo y el abanico de formatos de más arriba salen de la fuente del libro, no de escribirlos a mano. Cambia los datos, reconstruye, y la página cambia con ellos. Esta es la función detrás de la cifra de Londres:

def london_top() -> dict:
    import pandas as pd

    att = pd.read_csv(ROOT / "examples/london/data/attractions.csv")
    visits_col = next(c for c in att.columns if c.startswith("visits_"))
    top = att.loc[att[visits_col].idxmax()]
    return {"name": top["attraction"], "visits": int(top[visits_col]),
            "year": visits_col.removeprefix("visits_"), "n": len(att)}

Lo que necesitas

Tres cosas

  1. Una computadora en la que puedas instalar software: Windows, Mac o Linux.
  2. Una cuenta gratuita de GitHub.
  3. Una cuenta con un agente de programación.

Una nota honesta sobre el costo: Claude Code, por ejemplo, necesita un plan de pago o facturación por uso (consultado el 2026-11-03). El Capítulo 3 enumera lo que necesita cada agente.

Preguntas

Antes de descargarlo

¿De verdad es gratis?

Sí. Descarga el EPUB o lee la edición web: no hay que registrarse ni dar ningún correo.

¿Qué agente necesito?

Un agente de programación. Claude Code necesita una cuenta Pro, Max, Team, Enterprise o Console; Codex, iniciar sesión con ChatGPT o una clave de API; Antigravity, una cuenta de Google (consultado el 2026-11-03). El Capítulo 2 explica cómo elegir, y cuánto cuesta una conversación.

¿Funciona en Windows?

Sí: Windows, Mac o Linux. En Windows primero instalas Ubuntu con WSL; el Apéndice A y la página de Windows del taller, en inglés, te guían, un paso revisado a la vez.

¿Qué tan actualizado está?

La primera edición en español, de noviembre de 2026, se revisó con Quarto 1.10.20. Los precios, las versiones, las pantallas y los planes llevan la fecha en que se consultaron, y van a cambiar.

¿Puedo enseñar con él?

Sí: enseña con el libro y las diapositivas gratuitos, enlázalos y sigue el Apéndice I para dar el taller. Para copiar o adaptar el material, pide permiso antes.

¿Cómo se escribió?

Con un agente de programación con IA, como enseña el libro. De la declaración de uso de IA del libro:

Este libro se escribió con Claude Code (Claude Opus 5.5), que redactó los capítulos, el código, los diagramas y los scripts de medios y renderizó las dos ediciones, adaptando las diapositivas del taller, que a su vez se escribieron con Claude Code (Claude Opus 5.5, Sonnet 5.5, Opus 5 y Fable 5.1). La traducción al español también se hizo con Claude Code (Claude Opus 5.5), a partir de un glosario fijo de términos. Cada número que sale de los datos de los dos proyectos se calcula a partir de esos datos cuando se construye el libro; los precios, los tiempos y otros datos que cambian se citan con la fecha en que se consultaron. Ravi Kalia dirigió el trabajo y asume toda la responsabilidad por el contenido.

¿Hay una edición en inglés?

Sí: este libro es la traducción de Prompt, Check, Publish, que tiene su propia página, su edición web y su EPUB, con el mismo código, los mismos datos y los mismos números.
