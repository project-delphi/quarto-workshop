The method

One loop, every step

You ask, you check, Quarto rebuilds. Every hands-on step in the book goes once round this loop, so a mistake is caught while it is still small.

  1. Prompt

    Describe one small piece of work to a coding assistant, with its files and columns named.

  2. Check

    Read what changed, look at the result, compare it with the data. An assistant can be fluent, fast and wrong, so this step is never skipped, and it is always yours.

  3. Publish

    Quarto rebuilds every output from the checked source, the same way every time.

This page was built the way the book teaches

This page is a Quarto document. When it is built, code reads the book’s data, chapter list and cover, so every number on it, the contents below and the fan of formats above come from the book’s source, not from typing. Change the data, rebuild, and the page changes with it. This is the function behind the London number:

def london_top() -> dict:
    import pandas as pd

    att = pd.read_csv(ROOT / "examples/london/data/attractions.csv")
    visits_col = next(c for c in att.columns if c.startswith("visits_"))
    top = att.loc[att[visits_col].idxmax()]
    return {"name": top["attraction"], "visits": int(top[visits_col]),
            "year": visits_col.removeprefix("visits_"), "n": len(att)}

Who it’s for

No programming required

  • Researchers
  • Software practitioners
  • Data experts
  • Students

Anyone who works with data or code and needs to share the results. No programming is assumed: the book explains the Python the assistant writes, but you do not have to write it.

What you need

Three things

  1. A computer on which you can install software: Windows, Mac or Linux.
  2. A free GitHub account.
  3. An account with one coding assistant.

An honest note on cost: Claude Code, for one, needs a paid plan or pay-per-use billing (checked 2026-11-03). Chapter 3 lists what each assistant needs.

Questions

Before you download

Is it really free?

Yes. Download the EPUB or read the website edition: there is no sign-up and no email to give.

Which assistant do I need?

One coding assistant. Claude Code needs a Pro, Max, Team, Enterprise or Console account; Codex a ChatGPT sign-in or an API key; Antigravity a Google account (checked 2026-11-03). Chapter 2 explains how to choose, and what a conversation costs.

Does it work on Windows?

Yes: Windows, Mac or Linux. On Windows you first install Ubuntu with WSL; Appendix A and the workshop’s Windows page take you through it, one checked step at a time.

How current is it?

The first edition, of November 2026, was checked with Quarto 1.10.20. Prices, versions, screens and plans are given with the date they were checked, and will change.

Can I teach with it?

Yes: teach from the free book and slides, link to them, and follow Appendix I to run the workshop. To copy or adapt the material, ask the author first.

How was it written?

With an AI coding assistant, as the book teaches. From the book’s AI usage statement:

This book was written with Claude Code (Claude Opus 5.5), which drafted the chapters, code, diagrams and media scripts and rendered both editions, adapting the workshop slides, which were themselves written with Claude Code (Claude Opus 5.5, Sonnet 5.5, Opus 5 and Fable 5.1). Every number drawn from the two projects’ data is computed from that data when the book is built; prices, timings and other facts that change are cited with the date they were checked. The author directed the work and takes full responsibility for the content.
