Appendix J — Glossary

Keywords

Quarto, reproducible publishing, coding assistants, Markdown, Python, EPUB, data analysis, k-means clustering

The terms in this book that a newcomer may not know, each with a short definition and the section that explains it in context, where it comes with its reasons and an example. Code and file names are listed by their letters, without punctuation.

A

adjusted Rand index (ARI)
A score of how far two groupings agree beyond chance: 1 means identical, 0 no better than chance. See Section 11.2.
AGENTS.md
A plain Markdown file of rules at the top of a project, which the assistant reads at the start of every session. See Section 2.5.
alt text
The description that screen readers announce, and that appears if an image cannot load. See Section 4.7.
ALVA
The Association of Leading Visitor Attractions, the source of the London visitor counts; it counts only its member sites. See Section 1.1.
API
The vendor’s programming interface; API prices are what a program pays per token when it calls a model directly. See Section 2.2.

B

blank line
A line with nothing on it. In Markdown it starts a new paragraph, and a list needs one above it. See Section 4.1.
block quote
A quotation set off from the text beside a bar, typed with > at the start of each line. See Section 4.1.
bootstrap
Refitting on rows drawn again at random, to test whether a result survives other data. See Section 11.2.
box plot
A box holding the middle half of a group’s values, with lines at the median and the mean, and whiskers spanning the middle 90%. See Section 12.5.
branch
A movable label on a line of commits. See Section 7.1.

C

catch-up box
The one line to paste into your assistant where the book reaches a checkpoint; after catching up, you carry on reading from the box. See Section 4.11 and Figure 2.
cell options
Instructions for a code cell in its first lines, written as comments that start with #|. See Section 5.1 and Section 5.4.
checkpoint
A folder in the workshop’s checkpoints/ holding a project as it should be at the end of a hands-on block, with a README of catch-up steps. See Section 4.11 and Figure 2.
choropleth
A map whose areas are coloured by a value. See Section 14.7.
CI job
A build that a host such as GitLab runs on each push. See Section 7.2.
cited copy
Facts typed into a source from a cited file; they do not follow the file when it changes. See Section 4.8.
clone
To copy a repository, with its history, to your computer. See Section 3.6.
cluster
A group of zone-years that are similar to each other on the chosen variables, found by k-means. See Section 8.1.
code cell
A fenced block of code whose language is in braces, such as {python}; it runs when the document renders. See Section 1.2 and Section 5.1.
code fence
Three backticks that open and close a block of code; the word after them names the language, and the text inside is shown exactly as typed. See Section 4.9.
coding assistant
A program that writes files and runs commands at your request. See Figure 1 and Section 2.1.
command-line program
A program you run by typing a command in a terminal. See Section 1.2.
commit
A recorded state of the project’s files, with a message saying why it changed. See Section 7.1.
CommonMark
A precise specification of Markdown, which GFM extends. See Section 4.1.
confounder
A third variable that affects both the exposure and the outcome, so the two move together even if one has no effect on the other. See Section 13.2.
context
Everything sent to the model with a request: the conversation so far, the files read and the project’s rules. See Section 2.3.
control
Comparing like with like, so a third variable cannot explain a difference; the clusters offer a partial control. See Section 13.1.
correlation coefficient (r)
A measure from −1 to 1 of how two variables move together; 1 would mean they rise together along a straight line. See Section 10.3.
CSV
A table in plain text, one line per row, with commas between the columns. See Section 4.8.

D

dashboard
A page of charts and key numbers arranged in a grid. See Section 6.1.
diff
The lines a change added and removed. See Section 2.6.
difference-in-differences
Comparing places before and after a change with comparable places that did not change. See Section 13.2.
display-only fence
A code fence whose language is not in braces, such as python: the code is shown and never run. See Section 5.1.
div
A block of Markdown between two lines of three colons, whose class in braces tells Quarto what to make of it. See Section 6.1.
DIVIPOLA
DANE’s list of Colombia’s municipalities, which gives each a five-digit code: two digits for the department and three for the municipality. See Section 8.4.
DOI
A document’s permanent identifier; https://doi.org/ followed by it opens the publisher’s page. See Section 14.7.

E

ecological fallacy
Drawing conclusions about people from data about places. See Section 13.2.
effort
How long a model reasons before answering. See Chapter 2.
elbow
The k after which inertia stops falling much. See Section 11.2.
environment
A folder holding one version of Python and the packages one project uses, kept apart from every other project’s. See Section 4.10.
EPUB
An e-book format: a zipped set of web pages whose text reflows to fit the reader’s screen. See Section 5.6 and Section 14.3.
escape
A backslash before a Markdown mark, such as \*, which keeps the mark as typed. See Section 4.1.
Euclidean distance
Straight-line distance: the square root of the sum of squared differences across the features. See Section 10.3.
execute-dir
A project setting that makes every page read files from the project folder. See Section 14.4.

F

feature
A variable the clustering sees, and so one that defines the kinds. See Section 8.5.
flag column
A column that marks every value that was filled. See Section 10.1.
freeze
Quarto’s cache of computed results; with freeze: auto a page re-runs only when its own source changes, not when the data it reads change. See Section 1.4 and Section 14.4.
front matter
A block of settings in YAML between two lines of three dashes at the very top of a file. See Section 5.1 and Section 5.2.

G

gh
The GitHub command-line tool. See Section 3.5.
Git
The version-control tool: something like Track Changes for a whole folder, with a lasting history. See Section 1.4 and Section 7.1.
git restore
Puts a file back as it was at the last commit. See Section 7.5.
GitHub
The website that keeps a copy of a repository online. See Section 7.1.
GitHub Flavored Markdown (GFM)
The dialect of Markdown GitHub uses for README files and issues: CommonMark with tables, task lists, strikethrough and automatic links. See Section 4.1.
.gitignore
The list of files and folders Git should not track. See Section 7.3.
guard
A line that stops the render when a sentence’s words, not only its numbers, no longer match the data. See Section 14.4.

H

harness
The program on your computer that gives a model its tools, carries out its requests and asks you first. See Section 2.1.
home folder
Your own folder, written ~. See Section 3.3.
horizontal rule
A line across the page, typed as --- between blank lines. See Section 4.1.
hyperparameter
A setting an algorithm cannot learn from its own objective, such as k. See Section 11.2.

I

impute
To fill a missing value with an estimate. See Section 10.1.
index.qmd
The source of a website’s home page. See Section 7.3.
inertia
The sum of squared distances from each point to its cluster’s centre. See Section 11.1.
infant mortality
Deaths under one year of age per 1,000 live births. See Section 8.5.
inline code
Code in a sentence, such as {python} name, whose value Quarto writes into the sentence when the document renders. See Section 1.2 and Section 5.1.
IPM
The multidimensional poverty index: the share of a zone’s people who are poor in several respects at once, from the 2018 census. See Section 8.5.
IRCA
Colombia’s risk index for drinking water, from 0, every test passed, to 100, every test failed. See Section 8.2.
IRCA risk bands
Resolución 2115’s five ranges of the IRCA: no risk, low, medium, high and unfit. See Section 8.2.

J

join
Matching the rows of two tables by a column they share. See Section 8.4.
Jupyter
The computation engine that runs Python code cells (knitr does the same for R). See Section 1.2.

K

k
How many clusters k-means is asked to find. See Section 11.1.
kernel
The running Python process that executes a document’s cells, top to bottom. See Section 5.7.
k-means++
scikit-learn’s way of choosing starting centres that are spread out, which makes a stuck start less likely. See Section 11.1.

L

lead
The assistant session that starts sub-agents, waits for them and checks their results. See Section 6.2.
line break
A new line inside a paragraph, made by ending the line with a backslash. See Section 4.1.
listing
A page that lists other pages, such as every post of a blog, made by Quarto. See Section 14.4.
loadings
The weights of a principal component, which say what it measures. See Section 11.3.
lockfile
A file such as uv.lock that records the exact version of every package, for every system. See Section 4.10.
logarithm
A scale that measures ratios rather than differences: every doubling adds the same amount. See Section 10.1.
low-coverage
In a cluster’s name, half a standard deviation or more below the year’s average coverage: a relative position, not an absence of service. See Section 12.2.

M

Markdown
A way of writing structured text with a few punctuation marks, such as # before a heading. See Section 1.2 and Section 4.1.
MDM
DNP’s score of a municipality’s management and results, from 0 to 100. See Section 8.5.
median
The middle value, with half the values below it. See Section 9.1.
missing not at random
Gaps that depend on the unmeasured value itself, which no fill can repair. See Section 9.2.
model
A large language model: it reads and writes text and can reply with a request to use a tool. See Section 2.1.
monotonic
A relation in which one variable tends to rise as the other rises, though not necessarily along a straight line. See Section 13.1.
municipality-year
One municipality in one year: the unit of the municipal outcomes, infant mortality and dropout. See Section 12.4.

N

naming rule
A written rule that names each cluster from its profile: setting, relative coverage and the band of its median IRCA. See Section 12.2.
nano
The terminal’s own simple text editor: Ctrl+O and Enter save, Ctrl+X leaves. See Section 4.5.
nominal pesos
Pesos not adjusted for inflation. See Section 10.1.

O

outcome
A variable the analysis only compares between the kinds and never clusters on. See Section 8.5.

P

package
An add-on library that Python code imports, such as pandas for tables or matplotlib for charts. See Section 4.10.
Pandoc
The document converter inside Quarto that turns the executed Markdown into each output format. See Section 1.2.
Pandoc’s Markdown
The Markdown Quarto reads: GFM’s core marks, plus attributes in braces, footnotes, definition lists, citations and mathematics. See Section 4.1.
Parquet
A file format for tables that keeps each column’s type, so a code such as 05001 stays text. See Section 8.6.
PATH
The list of folders a terminal searches for programs, read when the terminal starts. See Section 3.4.
percentile
The value below which a given share of the values lies; the 5th and 95th bound the middle 90%. See Section 12.5.
platform tag
The part of a package file’s name that says which system and processor it was built for. See Section 4.10.
pre-render
A script Quarto runs before every render of a project, even of a single page. See Section 14.4.
principal component
A direction in which the data vary: a weighted sum of the features. See Section 11.3.
principal component analysis (PCA)
A method that finds the directions in which the data vary most and projects the rows onto them. See Section 11.3.
profile
A cluster’s mean of each feature over its rows, in z units. See Section 12.1.
prompt
The request you type into the assistant. See Section 2.6.
Prompt, Check, Publish
The loop this book teaches: prompt an assistant for one small step, check what it did, and let Quarto rebuild every output from the checked source. See Figure 1.
prompt (terminal)
The line ending in $ (or % on a Mac) that shows the terminal is ready, and who and where you are. See Section 3.3.
pull request
A proposal to merge a branch, which shows the difference line by line. See Section 7.1.
push
Copying commits to the shared repository on GitHub. See Section 7.1.

Q

quarto preview
Renders a file, serves it on a local address and renders it again every time the file is saved; Ctrl+C stops it. See Section 4.1 and Section 4.4.
Quarto project
A folder that a _quarto.yml file at its top turns into one website or book. See Section 7.3.

R

random seed
The number that starts the computer’s random-number generator, so random starts are the same on every run. See Section 11.1.
raw block
A block that Quarto passes untouched to one format, such as a raw Typst block. See Section 6.4.
render
To build a document’s outputs from its source; quarto render executes, converts and typesets. See Section 1.2 and Section 4.1.
repository
A project folder with its Git history. See Section 1.4.
reproducible
Someone else, or you later, can rebuild the same results from the same files with one command, and see where every number came from. See Section 1.4.
root folder
The folder you start an assistant in, where it reads, edits and runs commands. See Section 2.4.
rural zone
A municipality’s smaller settlements and dispersed countryside. See Section 8.4.

S

Saber 11
ICFES’s national exam for students finishing upper secondary school, with a global score from 0 to 500. See Section 8.3.
selection on the outcome
Keeping or dropping rows by the value being measured, so the rows kept are not typical. See Section 12.4.
self-supplied system
A water system that no utility runs. See Section 8.2.
SGP
Colombia’s system of national transfers to municipalities; the feature is its allocation for drinking water and sanitation, per person. See Section 8.5.
ShareAlike
The condition of a CC BY-SA licence that anything built from the data is shared under the same licence. See Section 14.5.
shell
The program behind the terminal that runs your commands. See Section 3.4.1.
silhouette
A score from −1 to 1 of how much closer each point is to its own cluster than to the next one, averaged over the points. See Section 11.2.
SIVIGILA
Colombia’s public-health surveillance system. See Section 14.8.
skewed
Mostly moderate values with a few very large ones. See Section 10.1.
slash command
A command such as /model, /clear or /exit, typed into the assistant itself. See Section 2.3.
small numbers
In small places a handful of deaths moves a rate a long way, so extreme rates are fragile. See Section 12.4.
Spearman’s ρ
A measure, from −1 through 0 to +1, of whether two variables rise and fall together in rank order. See Section 13.1.
standard deviation
Roughly, the typical distance of a value from the mean, in the variable’s own unit. See Section 10.1.
static site
A folder of HTML, CSS, JavaScript, images and documents, with no program running on a server. See Section 7.2.
strikethrough
Text crossed out, written between two tildes on each side, ~~Car~~. See Section 4.1.
sub-agent
A separate assistant session that your assistant starts for one task, with its own context. See Section 6.2.
sudo
Runs a command as the administrator, after asking for your password. See Section 3.2.
SVG
A drawing written as text, which a model writes as it writes code. See Chapter 2.

T

task list
A bulleted list whose items start with a box, [ ] empty or [x] ticked. See Section 4.1.
terminal
A window where you type commands instead of clicking. See Section 3.3.
token
A fragment of text a few characters long: the unit models read, write and are priced by. See Section 2.2.
Typst
A modern typesetting system that ships inside Quarto and makes its PDFs. See Section 1.2.

U

urban zone
A municipality’s head town (cabecera municipal). See Section 8.4.
utility-supplied IRCA
The IRCA of samples from systems a water utility runs (“prestadores”), which understates risk where people supply themselves. See Section 8.2.
uv
The tool that installs Python and manages each project’s packages. See Section 3.5 and Section 4.10.
uv run
Runs one command in the project’s environment, first bringing .venv up to date with uv.lock. See Section 4.10.

V

value box
A dashboard box that shows one key number with a label. See Section 6.1.
variance
The square of the standard deviation. See Section 10.3.

W

WebGL
The browser’s built-in 3-D graphics. See Section 6.5.
WSL
The Windows Subsystem for Linux, which runs Ubuntu inside Windows. See Chapter 3.

Y

YAML
A format for settings in which indentation is meaning. See Section 1.2 and Section 5.1.

Z

zone variable
A variable measured separately for a municipality’s urban and rural zones; a municipal variable has one value for the whole municipality, repeated on both rows. See Section 8.5.
zone-year
One municipality’s urban or rural zone in one year: one row of the water data, and Part III’s unit of analysis. See Section 8.4.
z-score
A value’s distance from its year’s mean, in standard deviations; it has no unit. See Section 10.1.
