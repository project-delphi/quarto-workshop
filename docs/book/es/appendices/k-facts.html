Apéndice K — Datos que cambian

Palabras clave

Quarto, publicación reproducible, agentes de programación, Markdown, Python, EPUB, análisis de datos, k-means

Los precios, los planes, las cuentas y las cuotas gratuitas cambian de un mes a otro, así que este libro los guarda en un solo lugar: un archivo de su fuente, book/facts.yml, que este apéndice imprime completo. Los capítulos lo citan en lugar de escribir un precio o un plan, así que cuando un dato cambia, una sola edición y una reconstrucción actualizan cada página que lo menciona, y también esta lista. Cada dato lleva la fecha en que se revisó contra la página oficial enlazada a su lado. Para cuando leas esto, algunos habrán cambiado: sigue el enlace, y confía en la página antes que en el libro.

Los agentes y sus cuentas

Qué cuenta necesita Claude Code. Claude Code necesita una cuenta Pro, Max, Ultra, Team, Enterprise o Console. Consultado el 2026-11-18, fuente.

Cuánto cuesta Claude Code. Claude Code, por ejemplo, necesita un plan de pago o facturación por uso. Consultado el 2026-11-18, fuente.

Qué cuenta necesita Codex. Codex, un inicio de sesión de ChatGPT o una clave de API. Consultado el 2026-11-18, fuente.

Qué cuenta necesita Antigravity. Antigravity, una cuenta de Google. Consultado el 2026-11-18, fuente.

El nivel gratuito de Antigravity. Una cuenta personal de Google puede usar Antigravity en su nivel gratuito, con una cuota que se renueva cada semana. Consultado el 2026-11-18, fuentes 1, 2.

Qué cuenta necesita OpenCode. OpenCode, un proveedor conectado desde dentro con /connect: un plan de ChatGPT, GitHub Copilot, una clave de API, un modelo local o una cuenta de OpenCode. Consultado el 2026-11-20, fuente.

Los modelos gratuitos de OpenCode. OpenCode ofrece modelos gratuitos por tiempo limitado una vez conectada una cuenta de OpenCode, y la lista cambia de una semana a otra. Consultado el 2026-11-20, fuentes 1, 2.

Qué pregunta OpenCode antes de actuar. El agente predeterminado de OpenCode edita archivos y ejecuta comandos sin preguntar, dentro de la carpeta o fuera de ella, salvo que se agreguen reglas con el efecto ask en opencode.jsonc. Consultado el 2026-11-20, fuentes 1, 2.

Un tope de gasto para Claude Code con facturación por API. Una cuenta de Claude Console puede limitar el gasto mensual de Claude Code con un límite de gasto del espacio de trabajo. Consultado el 2026-11-18, fuentes 1, 2.

Un tope de gasto para Codex con facturación por API. Una organización o un proyecto de la API de OpenAI puede fijar un límite estricto de gasto mensual, después del cual las solicitudes se detienen. Consultado el 2026-11-18, fuente.

Lo que GitHub da gratis

GitHub Codespaces en una cuenta personal gratuita. Una cuenta personal gratuita de GitHub incluye 120 horas de cómputo de Codespaces al mes, que en la máquina predeterminada de dos núcleos cuentan doble, o sea unas 60 horas de uso, y 15 GB de almacenamiento. Consultado el 2026-11-18, fuente.

GitHub Pages para repositorios privados. Una cuenta gratuita de GitHub publica Pages solo desde repositorios públicos; los repositorios privados necesitan un plan de pago, y un sitio que solo tu organización pueda ver necesita GitHub Enterprise Cloud. Consultado el 2026-11-18, fuente.

GitHub Actions en una cuenta gratuita. Los runners estándar de GitHub Actions son gratuitos en los repositorios públicos, y los repositorios privados de una cuenta gratuita reciben 12 dólares estadounidenses de cómputo al mes. Consultado el 2026-11-18, fuente.

Ramas protegidas en una cuenta gratuita. En una cuenta gratuita de GitHub, las ramas protegidas y los rulesets funcionan solo en repositorios públicos; los privados necesitan GitHub Pro, Team o Enterprise. Consultado el 2026-11-18, fuente.

Chats web gratuitos

Chats web con un plan gratuito. Claude, ChatGPT y Gemini tienen cada uno un plan gratuito. Consultado el 2026-11-12, fuentes 1, 2, 3.

Los modelos y sus precios

Modelos suficientes para los prompts de este libro. Sonnet de Claude con esfuerzo medio, o Haiku para ediciones pequeñas, o Sol de OpenAI con esfuerzo bajo. Consultado el 2026-11-12, fuentes 1, 2.

Dónde sugieren empezar los proveedores para el trabajo difícil. Anthropic sugiere empezar con Opus 5.5 para la mayoría de las cargas de trabajo, y OpenAI con GPT-6 Astra para el razonamiento y la programación complejos. Consultado el 2026-11-12, fuentes 1, 2.

Qué hacen los proveedores con tus datos

Los planes de consumo de Claude. En los planes Free, Pro, Max y Ultra de Anthropic, Claude Code incluido, las conversaciones se usan para entrenar nuevos modelos cuando tu configuración de privacidad lo permite, y se guardan cinco años si lo permite y treinta días si no. Consultado el 2026-11-18, fuente.

Los planes comerciales de Claude y la API. Con las condiciones comerciales de Anthropic (Team, Enterprise, la API), el código y los prompts no se usan para entrenar salvo que el cliente lo acepte, y se guardan treinta días de forma predeterminada; la retención cero de datos está disponible para las cuentas Enterprise que cumplen los requisitos. Consultado el 2026-11-18, fuentes 1, 2.

Lo que Claude Code guarda en tu computadora. Claude Code guarda las transcripciones de las sesiones en texto plano en ~/.claude/projects/ durante treinta días de forma predeterminada. Consultado el 2026-11-18, fuente.

La API de OpenAI. Los datos enviados a la API de OpenAI no se usan para entrenar salvo que lo aceptes; los registros de control de abusos se guardan hasta treinta días, y la retención cero de datos necesita la aprobación de OpenAI. Consultado el 2026-11-18, fuente.

Los planes empresariales de ChatGPT. Los datos de los espacios de trabajo de ChatGPT Business, Enterprise y Edu no se usan para entrenar los modelos de OpenAI de forma predeterminada. Consultado el 2026-11-18, fuente.

Qué política sigue Codex. La forma en que inicias sesión en Codex, con un plan de ChatGPT o con una clave de API, decide qué política de datos se aplica. Consultado el 2026-11-18, fuente.

Las condiciones de Antigravity. Las condiciones de Antigravity dicen que Google usa las interacciones para mejorar sus productos, que sus empleados y contratistas pueden revisarlas y que se puede desactivar en la configuración; piden no enviar información confidencial. Consultado el 2026-11-18, fuente.

Qué guardan los modelos gratuitos de OpenCode. Con un proveedor que conectes, se aplican sus condiciones; de los modelos gratuitos de OpenCode, algunos guardan los prompts y pueden usarlos para mejorar el modelo, y los puntos de acceso de prueba de NVIDIA piden no enviar datos personales ni confidenciales. Consultado el 2026-11-20, fuente.

Precios de los modelos

El precio de Haiku es para prompts de hasta 100,000 tokens; los más largos cuestan cinco veces más. Las suscripciones cuentan el uso de otra manera que los precios de la API, y los modelos que puedes elegir dependen de tu plan y de la versión del agente. Fuentes: las páginas de precios y de modelos de Anthropic, y la de modelos de OpenAI.

Estos son precios de API: lo que paga un programa por token cuando llama directamente al modelo (Sección 2.2). Léelos como una instantánea de la distancia entre los modelos pequeños y los grandes, no como números para hacer planes.
