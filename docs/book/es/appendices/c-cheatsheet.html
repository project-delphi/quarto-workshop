Apéndice C — Hoja de referencia

Palabras clave

Quarto, publicación reproducible, agentes de programación, Markdown, Python, EPUB, análisis de datos, k-means

Una referencia de una página para los patrones que usa este libro, con el capítulo que explica cada uno.

Encabezado YAML

Una sola fuente, varios formatos (Capítulo 7):

---
title: "Project Report"
author: "Author Name"
date: today
lang: en
format:
  html:
    toc: true
    format-links:
      - docx
      - {format: typst, text: PDF}
  docx: default
  typst:
    papersize: a4
---

Más formatos van en la misma lista:

format:
  # html, docx and typst as above, then:
  pptx: default
  revealjs:
    output-file: report-slides.html
  epub:
    toc: true

Celdas de código y código en línea

Las opciones van al principio de una celda, como comentarios #| (Sección 7.4):

  • #| label: fig-name numera la figura y permite que el texto la mencione como @fig-name.
  • #| echo: false oculta el código y muestra la salida.
  • #| eval: false muestra el código sin ejecutarlo.
  • #| fig-cap: "…" es el pie debajo de una figura.
  • #| fig-alt: "…" es el texto alternativo que anuncian los lectores de pantalla.
  • #| tbl-cap: "…" es el pie de una tabla.
  • #| output: asis trata el texto impreso como Markdown.

El código en línea pone un valor calculado en una oración (Sección 7.3):

The dataset contains `{python} len(df)` rows across `{python} df['year'].nunique()` years.

Dashboards

Un título de nivel 1 empieza una página, uno de nivel 2 una fila, y la salida de cada celda se convierte en una tarjeta (Sección 8.1):

---
title: "Operations dashboard"
format: dashboard
---

# Overview

## Row {height=30%}

::: {.valuebox icon="trophy" color="primary"}
Most visited
`{{python}} top_name`
:::

La fila siguiente tiene un gráfico:

## Row

```{python}
#| title: Visits by attraction
fig = px.bar(attractions, x="visits_2025", y="attraction")
fig
```

Asigna las figuras de Plotly y termina la celda con fig; nunca llames a fig.show() en un dashboard.

Sitios web

_quarto.yml convierte una carpeta en un sitio web (secciones 9.3 y 23.4):

project:
  type: website
  execute-dir: project
  pre-render: scripts/analysis.py
  render:
    - index.qmd
    - report.qmd
website:
  title: "My project"
  navbar:
    left:
      - {text: Report, href: report.qmd}
execute:
  freeze: false

Un menu: debajo de un elemento de la barra de navegación crea un menú desplegable (Sección 9.3).

Comandos del agente

Se escriben en el agente, no en la terminal: la Tabla 2.2 tiene los tres que controlan el costo y el contexto. Los nombres de OpenCode son otros. /models elige el modelo y /new empieza una sesión nueva; su documentación no enumera /clear ni /exit, y sale con Ctrl+C, Ctrl+D, o Ctrl+X y luego Q (documentación de OpenCode sobre su TUI y sus atajos de teclado, consultada el 2026-11-25).

Prompts

Un prompt confiable (Sección 2.6):

  1. Nombra las entradas y las salidas: nombres de archivo y de columna, entre comillas invertidas.
  2. Hace una sola tarea.
  3. Termina con una comprobación: “renderízalo y dime qué archivo escribió”, “comprueba que el PDF tenga una página”.
  4. Respeta los datos: “calcula cada número a partir de los archivos citados; nunca inventes uno”.
