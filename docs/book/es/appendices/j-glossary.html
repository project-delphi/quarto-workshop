Apéndice J — Glosario

Palabras clave

Quarto, publicación reproducible, agentes de programación, Markdown, Python, EPUB, análisis de datos, k-means

Los términos de este libro que alguien que empieza puede no conocer, cada uno con una definición corta y la sección que lo explica en contexto, donde viene con sus razones y un ejemplo. El código y los nombres de archivo se ordenan por sus letras, sin la puntuación; los términos que el libro usa en inglés se ordenan como se escriben.

A

agente de programación
Un programa que escribe archivos y ejecuta comandos cuando se lo pides, y actúa en la carpeta de tu proyecto en un ciclo hasta terminar el paso, donde un chat web te entrega texto para copiar. Ver Figura 1 y Sección 2.1.
AGENTS.md
Un archivo de Markdown simple con reglas, en la parte de arriba de un proyecto, que el agente lee al comienzo de cada sesión. Ver Sección 2.5.
ALVA
La Association of Leading Visitor Attractions, la fuente de los conteos de visitantes de Londres; cuenta solo a sus sitios miembro. Ver Sección 1.1.
análisis de componentes principales (PCA)
Un método que encuentra las direcciones en las que más varían los datos y proyecta las filas sobre ellas. Ver Sección 20.3.
API
La interfaz de programación del proveedor; los precios de API son lo que paga un programa por token cuando llama directamente a un modelo. Ver Sección 2.2.
apt
El gestor de paquetes de Ubuntu: apt update actualiza su lista de software y apt install instala. Ver Sección 4.2.
árbol de trabajo
Los archivos del proyecto tal como están ahora; “limpio” significa que coinciden con el último commit. Ver Sección 5.4.
archivo de bloqueo
Un archivo como uv.lock que registra la versión exacta de cada paquete, para cada sistema (en inglés, lockfile). Ver Sección 6.10.
archivo de marca
_brand.yml: los colores, las fuentes y el logo de una empresa, declarados una sola vez; Quarto los aplica a las páginas web, las presentaciones de Reveal.js, los PDF de Typst y los dashboards. Ver Sección 12.1.
artefacto
Un archivo que produce una ejecución de CI y que se guarda para descargarlo desde la página de la ejecución, como los informes PDF del mes. Ver Sección 15.6.
asimétrica
Con valores sobre todo moderados y unos pocos muy grandes. Ver Sección 19.1.

B

baja cobertura
En el nombre de un clúster, media desviación estándar o más por debajo de la cobertura promedio del año: una posición relativa, no una ausencia de servicio. Ver Sección 21.2.
bloque de código delimitado
Tres comillas invertidas que abren y cierran un bloque de código; la palabra que las sigue nombra el lenguaje, y el texto de adentro se muestra exactamente como se escribió. Ver Sección 6.9.
bloque sin procesar
Un bloque que Quarto le pasa intacto a un formato, como un bloque de Typst sin procesar (en inglés, raw block). Ver Sección 8.4.
bloque solo de muestra
Un bloque de código delimitado cuyo lenguaje no está entre llaves, como python: el código se muestra y nunca se ejecuta. Ver Sección 7.1.
bootstrap
Volver a ajustar sobre filas sacadas otra vez al azar, para comprobar si un resultado sobrevive a otros datos. Ver Sección 20.2.

C

calibración
Cuánto coinciden las probabilidades que predice un modelo con las tasas observadas: de los contactos a los que les da un 20%, más o menos uno de cada cinco debería suscribirse. Ver Sección 10.3.
característica
Una variable que ve el agrupamiento, y por lo tanto una que define los tipos. Ver Sección 17.5.
cargas
Los pesos de una componente principal, que dicen qué mide. Ver Sección 20.3.
carpeta personal
Tu propia carpeta, que se escribe ~. Ver Sección 4.3.
carpeta raíz
La carpeta en la que inicias un agente, donde lee, edita y ejecuta comandos. Ver Sección 2.4.
celda de código
Un bloque de código delimitado cuyo lenguaje está entre llaves, como {python}; se ejecuta cuando se renderiza el documento. Ver Sección 1.2 y Sección 7.1.
cita en bloque
Una cita separada del texto por una barra a su lado, escrita con > al comienzo de cada línea. Ver Sección 6.1.
citeproc
El procesador de citas que usa Pandoc para dar formato a las citas y a la lista de referencias en un estilo CSL; citeproc: true hace que un PDF de Typst también lo use. Ver Sección 13.3.
clave de API
Una cadena secreta que identifica tu cuenta ante la interfaz de programación de un proveedor, que cobra cada solicitud. Mantenla fuera de los archivos que compartes o a los que les haces commit. Ver Sección 4.1.
clonar
Copiar un repositorio, con su historial, a tu computadora. Ver Sección 4.6.
clúster
Un grupo de zonas-año que se parecen entre sí en las variables elegidas, encontrado por k-means. Ver Sección 17.1.
codespace
Una computadora que GitHub ejecuta por ti, que se abre en tu navegador y se configura a partir del archivo de contenedor de desarrollo de un repositorio. Ver Sección 4.8.
código en línea
Código dentro de una oración, como {python} name, cuyo valor escribe Quarto en la oración cuando se renderiza el documento. Ver Sección 1.2 y Sección 7.1.
codo
El k a partir del cual la inercia deja de bajar mucho. Ver Sección 20.2.
coeficiente de correlación (r)
Una medida de −1 a 1 de cómo se mueven juntas dos variables; 1 significaría que suben juntas a lo largo de una línea recta. Ver Sección 19.3.
columna indicadora
Una columna que marca cada valor que se llenó. Ver Sección 19.1.
comando slash
Un comando como /model, /clear o /exit, que se escribe en el propio agente. Ver Sección 2.3.
commit
Un estado registrado de los archivos del proyecto, con un mensaje que dice por qué cambió. Ver Sección 5.4 y Sección 9.1.
CommonMark
Una especificación precisa de Markdown, que GFM amplía. Ver Sección 6.1.
CompartirIgual
La condición de una licencia CC BY-SA según la cual todo lo que se construya a partir de los datos se comparte con la misma licencia (en inglés, ShareAlike). Ver Sección 23.5.
completar con Tab
Presionar Tab en la terminal para terminar un nombre de archivo o de carpeta; dos veces enumera los nombres que encajan. Ver Sección 5.1.
componente principal
Una dirección en la que varían los datos: una suma ponderada de las características. Ver Sección 20.3.
contenedor de desarrollo
Un archivo, .devcontainer/devcontainer.json, que enumera lo que instala un entorno ya preparado, para que un codespace o un contenedor arranque con las herramientas correctas (en inglés, dev container). Ver Sección 4.8.
contexto
Todo lo que se le envía al modelo con una solicitud: la conversación hasta ahí, los archivos leídos y las reglas del proyecto. Ver Sección 2.3.
control
Comparar lo comparable, para que una tercera variable no pueda explicar una diferencia; los clústeres ofrecen un control parcial. Ver Sección 22.1.
copia citada
Datos escritos en una fuente a partir de un archivo citado; no siguen al archivo cuando cambia. Ver Sección 6.8.
cron
Una línea de cinco campos (minuto, hora, día del mes, mes, día de la semana) que dice cuándo se ejecuta una tarea programada; GitHub Actions la lee en UTC de forma predeterminada. Ver Sección 15.6.
CSL
El lenguaje de estilos de citas (Citation Style Language): un estilo de citas escrito como archivo, como el de APA o el de una revista, que se nombra con csl:. Ver Sección 13.3.
CSV
Una tabla en texto plano, una línea por fila, con comas entre las columnas. Ver Sección 6.8.
cuadro de valor
Un cuadro de dashboard que muestra una cifra clave con una etiqueta (en inglés, value box). Ver Sección 8.1.
curl
Un pequeño programa que descarga un archivo desde una dirección web. Ver Sección 4.2.

D

dashboard
Una página de gráficos y cifras clave organizados en una cuadrícula. Ver Sección 8.1.
descripción
El resumen de una página en una sola oración, en su encabezado YAML, que alimenta los listados, la búsqueda, la metaetiqueta de la página y las tarjetas para redes sociales; no puede calcular. Ver Sección 12.4.
desviación estándar
Más o menos, la distancia típica de un valor a la media, en la unidad propia de la variable. Ver Sección 19.1.
diagrama de caja
Una caja que contiene la mitad central de los valores de un grupo, con líneas en la mediana y en la media, y bigotes que abarcan el 90% central. Ver Sección 21.5.
diferencias en diferencias
Comparar lugares antes y después de un cambio con lugares comparables que no cambiaron. Ver Sección 22.2.
diff
Las líneas que agregó y eliminó un cambio. Ver Sección 2.6 y Sección 5.5.
distancia euclidiana
La distancia en línea recta: la raíz cuadrada de la suma de las diferencias al cuadrado en todas las características. Ver Sección 19.3.
div
Un bloque de Markdown entre dos líneas de tres signos de dos puntos, cuya clase entre llaves le dice a Quarto qué hacer con él. Ver Sección 8.1.
DIVIPOLA
La lista de municipios de Colombia del DANE, que le da a cada uno un código de cinco dígitos: dos para el departamento y tres para el municipio. Ver Sección 17.4.
documento de referencia
Un archivo de Word o PowerPoint cuyos estilos, tema y diseños copia Quarto en su salida, y que se indica con reference-doc. Ver Sección 11.6.
DOI
El identificador permanente de un documento; https://doi.org/ seguido de él abre la página de la editorial. Ver Sección 23.7.

E

encabezado YAML
Un bloque de configuración en YAML entre dos líneas de tres guiones, al comienzo mismo de un archivo (en inglés, front matter). Ver Sección 7.1 y Sección 7.2.
entorno
Una carpeta que contiene una versión de Python y los paquetes que usa un proyecto, separados de los de cualquier otro proyecto. Ver Sección 6.10.
EPUB
Un formato de libro electrónico: un conjunto comprimido de páginas web cuyo texto se reacomoda a la pantalla del lector. Ver Sección 7.6 y Sección 23.3.
escapar
Poner una barra invertida antes de una marca de Markdown, como \*, para que la marca quede tal como se escribió. Ver Sección 6.1.
esfuerzo
Cuánto razona un modelo antes de responder. Ver Capítulo 2.
etiqueta de plataforma
La parte del nombre del archivo de un paquete que dice para qué sistema y procesador se construyó. Ver Sección 6.10.
execute-dir
Una opción de proyecto que hace que cada página lea los archivos desde la carpeta del proyecto. Ver Sección 23.4.

F

falacia ecológica
Sacar conclusiones sobre personas a partir de datos sobre lugares. Ver Sección 22.2.
faltantes no aleatorios
Vacíos que dependen del propio valor que no se midió, y que ningún relleno puede reparar. Ver Sección 18.2.
ficha del modelo
Un documento breve que acompaña a un modelo: qué es y para qué sirve, cómo rinde en general y para los grupos a los que afecta, y sus límites conocidos (Mitchell y colaboradores, 2019; en inglés, model card). Ver Sección 10.2.
fragmento
Una parte de una diapositiva que se revela paso a paso, escrita con . . . o ::: {.fragment}. Ver Sección 11.2.
freeze
El caché de resultados calculados de Quarto; con freeze: auto una página se vuelve a ejecutar solo cuando cambia su propia fuente, no cuando cambian los datos que lee. Ver Sección 1.4 y Sección 23.4.

G

gestor de paquetes
Un programa que instala software de una colección y lo mantiene al día, como apt en Ubuntu o Homebrew en una Mac. Ver Sección 4.2.
gh
La herramienta de línea de comandos de GitHub. Ver Sección 4.5.
Git
La herramienta de control de versiones: algo así como el control de cambios para una carpeta entera, con un historial que perdura. Ver Sección 1.4 y Sección 9.1.
git add
Elige qué entra en el próximo commit; git add . toma todos los archivos de la carpeta que .gitignore no deja fuera. Ver Sección 5.4.
git diff
Muestra las líneas cambiadas desde el último commit: una línea que empieza con - se eliminó, una que empieza con + se agregó. Ver Sección 5.5.
git log
Enumera los commits, del más reciente al más viejo; git log --oneline le da una línea a cada uno. Ver Sección 5.4.
git restore
Devuelve un archivo a como estaba en el último commit. Ver Sección 5.5 y Sección 9.5.
git status
Dice qué archivos cambiaron desde el último commit, y cuáles no sigue Git. Ver Sección 5.4.
GitHub
El sitio web que guarda una copia de un repositorio en línea. Ver Sección 9.1.
GitHub Flavored Markdown (GFM)
El dialecto de Markdown que usa GitHub para los archivos README y los issues: CommonMark con tablas, listas de tareas, tachado y enlaces automáticos. Ver Sección 6.1.
.gitignore
La lista de archivos y carpetas que Git no debe seguir. Ver Sección 5.4 y Sección 9.3.
guarda
Una línea que detiene el renderizado cuando las palabras de una oración, no solo sus números, ya no coinciden con los datos. Ver Sección 23.4.

H

harness
El programa en tu computadora que le da a un modelo sus herramientas, lleva a cabo sus solicitudes y te pregunta primero. Ver Sección 2.1.
hiperparámetro
Una opción que un algoritmo no puede aprender de su propio objetivo, como k. Ver Sección 20.2.
Homebrew
Un gestor de paquetes para Mac, que instala herramientas de línea de comandos; este libro no lo necesita. Ver Sección 4.5.

I

imputar
Llenar un valor faltante con una estimación. Ver Sección 19.1.
index.qmd
La fuente de la página de inicio de un sitio web. Ver Sección 9.3.
indicador (de la terminal)
La línea que termina en $ (o en % en una Mac) y que muestra que la terminal está lista, y quién eres y dónde estás (en inglés, prompt). Ver Sección 4.3.
índice de Rand ajustado (ARI)
Un puntaje de cuánto coinciden dos agrupamientos más allá del azar: 1 significa idénticos, 0 no mejor que el azar. Ver Sección 20.2.
inercia
La suma de las distancias al cuadrado de cada punto al centro de su clúster. Ver Sección 20.1.
integración continua (CI)
Reconstruir y revisar un proyecto automáticamente, en una máquina limpia, para cada cambio propuesto; aquí, un workflow de GitHub Actions que ejecuta los propios comandos de reconstrucción del proyecto en cada pull request. Ver Capítulo 15.
IPM
El Índice de Pobreza Multidimensional: la proporción de las personas de una zona que son pobres en varios aspectos a la vez, según el censo de 2018. Ver Sección 17.5.
IRCA
El Índice de Riesgo de la Calidad del Agua para consumo humano de Colombia, de 0, todas las pruebas aprobadas, a 100, todas reprobadas. Ver Sección 17.2.
IRCA de prestadores
El IRCA de las muestras de sistemas que opera un prestador del servicio de agua, que subestima el riesgo donde la gente se autoabastece. Ver Sección 17.2.

J

Jupyter
El motor de cálculo que ejecuta las celdas de código de Python (knitr hace lo mismo para R). Ver Sección 1.2.

K

k
Cuántos clústeres se le pide encontrar a k-means. Ver Sección 20.1.
kernel
El proceso de Python en ejecución que ejecuta las celdas de un documento, de arriba hacia abajo. Ver Sección 7.7.
k-means++
La forma en que scikit-learn elige centros iniciales dispersos, lo que hace menos probable un inicio atascado. Ver Sección 20.1.

L

límite de gasto
Un tope mensual de lo que puede gastar una cuenta de API, que se fija en el sitio del proveedor; las solicitudes se detienen cuando se alcanza. Ver Sección 4.1.
línea en blanco
Una línea sin nada. En Markdown empieza un párrafo nuevo, y una lista necesita una antes. Ver Sección 6.1.
línea horizontal
Una línea que cruza la página, escrita como --- entre líneas en blanco. Ver Sección 6.1.
lista de tareas
Una lista con viñetas cuyos elementos empiezan con una casilla, [ ] vacía o [x] marcada. Ver Sección 6.1.
listado
Una página que enumera otras páginas, como cada entrada de un blog, hecha por Quarto. Ver Sección 23.4.
logaritmo
Una escala que mide razones y no diferencias: cada vez que algo se duplica, suma lo mismo. Ver Sección 19.1.

M

mapa coroplético
Un mapa cuyas áreas se colorean según un valor. Ver Sección 23.7.
Markdown
Una forma de escribir texto estructurado con unos pocos signos de puntuación, como # antes de un título. Ver Sección 1.2 y Sección 6.1.
Markdown de Pandoc
El Markdown que lee Quarto: las marcas básicas de GFM, más atributos entre llaves, notas al pie, listas de definiciones, citas bibliográficas y matemáticas. Ver Sección 6.1.
MDM
La Medición del Desempeño Municipal del DNP, un puntaje de la gestión y los resultados de un municipio, de 0 a 100. Ver Sección 17.5.
mediana
El valor del medio, con la mitad de los valores por debajo. Ver Sección 18.1.
modelo
Un modelo de lenguaje grande: lee y escribe texto, y puede responder con una solicitud para usar una herramienta. Ver Sección 2.1.
monótona
Una relación en la que una variable tiende a subir cuando la otra sube, aunque no necesariamente a lo largo de una línea recta. Ver Sección 22.1.
mortalidad infantil
Las muertes de menores de un año por cada 1,000 nacidos vivos. Ver Sección 17.5.
municipio-año
Un municipio en un año: la unidad de las variables de resultado municipales, la mortalidad infantil y la deserción. Ver Sección 21.4.

N

nano
El editor de texto simple de la propia terminal: Ctrl+O y Enter guardan, Ctrl+X sale. Ver Sección 5.5 y Sección 6.5.
niveles de riesgo del IRCA
Los cinco rangos del IRCA de la Resolución 2115: sin riesgo, bajo, medio, alto e inviable sanitariamente. Ver Sección 17.2.
notas de presentación
Lo que quien presenta dirá sobre una diapositiva, escrito en un bloque ::: {.notes}: se ve en la vista del presentador (presiona S), no en la pantalla. Ver Sección 11.2.
notebook
Un archivo de Jupyter (.ipynb) con código, salidas y texto; Quarto lo renderiza tal como se guardó, o primero lo ejecuta con --execute. Ver Sección 3.4.
números pequeños
En los lugares pequeños, un puñado de muertes mueve mucho una tasa, así que las tasas extremas son frágiles. Ver Sección 21.4.

O

opciones de celda
Instrucciones para una celda de código en sus primeras líneas, escritas como comentarios que empiezan con #|. Ver Sección 7.1 y Sección 7.4.

P

Pandoc
El conversor de documentos dentro de Quarto que convierte el Markdown ejecutado en cada formato de salida. Ver Sección 1.2.
papermill
El paquete de Python que pone en un documento los valores de los parámetros de un renderizado; un renderizado con -P lo necesita en el entorno del proyecto. Ver Sección 14.1.
paquete
Una biblioteca adicional que importa el código de Python, como pandas para tablas o matplotlib para gráficos. Ver Sección 6.10.
parámetro
Un valor que un documento recibe al renderizarse, con un valor predeterminado en una celda etiquetada parameters; -P name:value lo reemplaza en un solo renderizado. Ver Sección 14.1.
parcial de plantilla
Una parte con nombre de la plantilla con la que Quarto escribe un formato, como typst-show.typ de Typst, que un proyecto puede reemplazar por la suya. Ver Sección 13.5.
Parquet
Un formato de archivo para tablas que conserva el tipo de cada columna, así que un código como 05001 sigue siendo texto. Ver Sección 17.6.
PATH
La lista de carpetas en las que una terminal busca programas, que se lee cuando la terminal arranca. Ver Sección 4.4.
percentil
El valor por debajo del cual queda una proporción dada de los valores; el 5 y el 95 delimitan el 90% central. Ver Sección 21.5.
perfil
La media de cada característica de un clúster sobre sus filas, en unidades z. Ver Sección 21.1.
pesos corrientes
Pesos no ajustados por inflación (pesos nominales). Ver Sección 19.1.
Pide, revisa, publica
El ciclo que enseña este libro: pídele a un agente un paso pequeño, revisa lo que hizo y deja que Quarto reconstruya cada salida desde la fuente revisada (en inglés, Prompt, Check, Publish). Ver Figura 1.
pre-render
Un script que Quarto ejecuta antes de cada renderizado de un proyecto, incluso de una sola página. Ver Sección 23.4.
programa de línea de comandos
Un programa que ejecutas escribiendo un comando en una terminal. Ver Sección 1.2.
prompt
La solicitud que le escribes al agente. Ver Sección 2.6.
proxy
Un servidor por el que la red de una empresa hace pasar todo el tráfico web; puede bloquear descargas. Ver Sección 4.1.
proyecto de Quarto
Una carpeta que un archivo _quarto.yml en su parte de arriba convierte en un sitio web o un libro. Ver Sección 9.3.
pull request
Una propuesta para hacer merge de una rama, que muestra la diferencia línea por línea. Ver Sección 9.1.
puntaje z
La distancia de un valor a la media de su año, en desviaciones estándar; no tiene unidad. Ver Sección 19.1.
punto de control
Una carpeta de checkpoints/ del taller que contiene un proyecto tal como debería estar al final de un bloque práctico, con un README de pasos para ponerse al día. Ver Sección 6.11 y Figura 2.
push
Copiar commits al repositorio compartido en GitHub. Ver Sección 9.1.

Q

quarto preview
Renderiza un archivo, lo sirve en una dirección local y lo vuelve a renderizar cada vez que se guarda; Ctrl+C lo detiene. Ver Sección 6.1 y Sección 6.4.

R

rama
Una etiqueta móvil sobre una línea de commits. Ver Sección 9.1.
rama protegida
Una rama, normalmente main, que GitHub solo deja cambiar mediante un pull request cuyas comprobaciones obligatorias pasaron. Ver Sección 15.4.
recuadro para ponerte al día
La línea que se pega en el agente donde el libro llega a un punto de control; después de ponerte al día, sigues leyendo desde el recuadro. Ver Sección 6.11 y Figura 2.
referencia cruzada
Un enlace a una sección, tabla o figura numerada, escrito @sec-…, @tbl-… o @fig-…, que se renderiza como “Sección 2” o “Tabla 1” en todos los formatos. Ver Sección 10.3.
regla de nombres
Una regla escrita que le pone nombre a cada clúster a partir de su perfil: entorno, cobertura relativa y el nivel de la mediana de su IRCA. Ver Sección 21.2.
relación de contraste
Cuánto se destaca el texto de su fondo, de 1:1 a 21:1; WCAG 2.2 pide al menos 4.5:1 para el texto normal. Ver Sección 11.4.
renderizar
