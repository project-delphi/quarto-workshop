Apéndice J — Glosario

Palabras clave

Quarto, publicación reproducible, agentes de programación, Markdown, Python, EPUB, análisis de datos, k-means

Los términos de este libro que alguien que empieza puede no conocer, cada uno con una definición corta y la sección que lo explica en contexto, donde viene con sus razones y un ejemplo. El código y los nombres de archivo se ordenan por sus letras, sin la puntuación; los términos que el libro usa en inglés se ordenan como se escriben.

A

agente de programación
Un programa que escribe archivos y ejecuta comandos cuando se lo pides, y actúa en la carpeta de tu proyecto en un ciclo hasta terminar el paso, donde un chat web te entrega texto para copiar. Ver Figura 1 y Sección 2.1.
AGENTS.md
Un archivo de Markdown simple con reglas, en la parte de arriba de un proyecto, que el agente lee al comienzo de cada sesión. Ver Sección 2.5.
ALVA
La Association of Leading Visitor Attractions, la fuente de los conteos de visitantes de Londres; cuenta solo a sus sitios miembro. Ver Sección 1.1.
análisis de componentes principales (PCA)
Un método que encuentra las direcciones en las que más varían los datos y proyecta las filas sobre ellas. Ver Sección 11.3.
API
La interfaz de programación del proveedor; los precios de API son lo que paga un programa por token cuando llama directamente a un modelo. Ver Sección 2.2.
archivo de bloqueo
Un archivo como uv.lock que registra la versión exacta de cada paquete, para cada sistema (en inglés, lockfile). Ver Sección 4.10.
asimétrica
Con valores sobre todo moderados y unos pocos muy grandes. Ver Sección 10.1.

B

baja cobertura
En el nombre de un clúster, media desviación estándar o más por debajo de la cobertura promedio del año: una posición relativa, no una ausencia de servicio. Ver Sección 12.2.
bloque de código delimitado
Tres comillas invertidas que abren y cierran un bloque de código; la palabra que las sigue nombra el lenguaje, y el texto de adentro se muestra exactamente como se escribió. Ver Sección 4.9.
bloque sin procesar
Un bloque que Quarto le pasa intacto a un formato, como un bloque de Typst sin procesar (en inglés, raw block). Ver Sección 6.4.
bloque solo de muestra
Un bloque de código delimitado cuyo lenguaje no está entre llaves, como python: el código se muestra y nunca se ejecuta. Ver Sección 5.1.
bootstrap
Volver a ajustar sobre filas sacadas otra vez al azar, para comprobar si un resultado sobrevive a otros datos. Ver Sección 11.2.

C

característica
Una variable que ve el agrupamiento, y por lo tanto una que define los tipos. Ver Sección 8.5.
cargas
Los pesos de una componente principal, que dicen qué mide. Ver Sección 11.3.
carpeta personal
Tu propia carpeta, que se escribe ~. Ver Sección 3.3.
carpeta raíz
La carpeta en la que inicias un agente, donde lee, edita y ejecuta comandos. Ver Sección 2.4.
celda de código
Un bloque de código delimitado cuyo lenguaje está entre llaves, como {python}; se ejecuta cuando se renderiza el documento. Ver Sección 1.2 y Sección 5.1.
cita en bloque
Una cita separada del texto por una barra a su lado, escrita con > al comienzo de cada línea. Ver Sección 4.1.
clonar
Copiar un repositorio, con su historial, a tu computadora. Ver Sección 3.6.
clúster
Un grupo de zonas-año que se parecen entre sí en las variables elegidas, encontrado por k-means. Ver Sección 8.1.
código en línea
Código dentro de una oración, como {python} name, cuyo valor escribe Quarto en la oración cuando se renderiza el documento. Ver Sección 1.2 y Sección 5.1.
codo
El k a partir del cual la inercia deja de bajar mucho. Ver Sección 11.2.
coeficiente de correlación (r)
Una medida de −1 a 1 de cómo se mueven juntas dos variables; 1 significaría que suben juntas a lo largo de una línea recta. Ver Sección 10.3.
columna indicadora
Una columna que marca cada valor que se llenó. Ver Sección 10.1.
comando slash
Un comando como /model, /clear o /exit, que se escribe en el propio agente. Ver Sección 2.3.
commit
Un estado registrado de los archivos del proyecto, con un mensaje que dice por qué cambió. Ver Sección 7.1.
CommonMark
Una especificación precisa de Markdown, que GFM amplía. Ver Sección 4.1.
CompartirIgual
La condición de una licencia CC BY-SA según la cual todo lo que se construya a partir de los datos se comparte con la misma licencia (en inglés, ShareAlike). Ver Sección 14.5.
componente principal
Una dirección en la que varían los datos: una suma ponderada de las características. Ver Sección 11.3.
contexto
Todo lo que se le envía al modelo con una solicitud: la conversación hasta ahí, los archivos leídos y las reglas del proyecto. Ver Sección 2.3.
control
Comparar lo comparable, para que una tercera variable no pueda explicar una diferencia; los clústeres ofrecen un control parcial. Ver Sección 13.1.
copia citada
Datos escritos en una fuente a partir de un archivo citado; no siguen al archivo cuando cambia. Ver Sección 4.8.
CSV
Una tabla en texto plano, una línea por fila, con comas entre las columnas. Ver Sección 4.8.
cuadro de valor
Un cuadro de dashboard que muestra una cifra clave con una etiqueta (en inglés, value box). Ver Sección 6.1.

D

dashboard
Una página de gráficos y cifras clave organizados en una cuadrícula. Ver Sección 6.1.
desviación estándar
Más o menos, la distancia típica de un valor a la media, en la unidad propia de la variable. Ver Sección 10.1.
diagrama de caja
Una caja que contiene la mitad central de los valores de un grupo, con líneas en la mediana y en la media, y bigotes que abarcan el 90% central. Ver Sección 12.5.
diferencias en diferencias
Comparar lugares antes y después de un cambio con lugares comparables que no cambiaron. Ver Sección 13.2.
diff
Las líneas que agregó y eliminó un cambio. Ver Sección 2.6.
distancia euclidiana
La distancia en línea recta: la raíz cuadrada de la suma de las diferencias al cuadrado en todas las características. Ver Sección 10.3.
div
Un bloque de Markdown entre dos líneas de tres signos de dos puntos, cuya clase entre llaves le dice a Quarto qué hacer con él. Ver Sección 6.1.
DIVIPOLA
La lista de municipios de Colombia del DANE, que le da a cada uno un código de cinco dígitos: dos para el departamento y tres para el municipio. Ver Sección 8.4.
DOI
El identificador permanente de un documento; https://doi.org/ seguido de él abre la página de la editorial. Ver Sección 14.7.

E

encabezado YAML
Un bloque de configuración en YAML entre dos líneas de tres guiones, al comienzo mismo de un archivo (en inglés, front matter). Ver Sección 5.1 y Sección 5.2.
entorno
Una carpeta que contiene una versión de Python y los paquetes que usa un proyecto, separados de los de cualquier otro proyecto. Ver Sección 4.10.
EPUB
Un formato de libro electrónico: un conjunto comprimido de páginas web cuyo texto se reacomoda a la pantalla del lector. Ver Sección 5.6 y Sección 14.3.
escapar
Poner una barra invertida antes de una marca de Markdown, como \*, para que la marca quede tal como se escribió. Ver Sección 4.1.
esfuerzo
Cuánto razona un modelo antes de responder. Ver Capítulo 2.
etiqueta de plataforma
La parte del nombre del archivo de un paquete que dice para qué sistema y procesador se construyó. Ver Sección 4.10.
execute-dir
Una opción de proyecto que hace que cada página lea los archivos desde la carpeta del proyecto. Ver Sección 14.4.

F

falacia ecológica
Sacar conclusiones sobre personas a partir de datos sobre lugares. Ver Sección 13.2.
faltantes no aleatorios
Vacíos que dependen del propio valor que no se midió, y que ningún relleno puede reparar. Ver Sección 9.2.
freeze
El caché de resultados calculados de Quarto; con freeze: auto una página se vuelve a ejecutar solo cuando cambia su propia fuente, no cuando cambian los datos que lee. Ver Sección 1.4 y Sección 14.4.

G

gh
La herramienta de línea de comandos de GitHub. Ver Sección 3.5.
Git
La herramienta de control de versiones: algo así como el control de cambios para una carpeta entera, con un historial que perdura. Ver Sección 1.4 y Sección 7.1.
git restore
Devuelve un archivo a como estaba en el último commit. Ver Sección 7.5.
GitHub
El sitio web que guarda una copia de un repositorio en línea. Ver Sección 7.1.
GitHub Flavored Markdown (GFM)
El dialecto de Markdown que usa GitHub para los archivos README y los issues: CommonMark con tablas, listas de tareas, tachado y enlaces automáticos. Ver Sección 4.1.
.gitignore
La lista de archivos y carpetas que Git no debe seguir. Ver Sección 7.3.
guarda
Una línea que detiene el renderizado cuando las palabras de una oración, no solo sus números, ya no coinciden con los datos. Ver Sección 14.4.

H

harness
El programa en tu computadora que le da a un modelo sus herramientas, lleva a cabo sus solicitudes y te pregunta primero. Ver Sección 2.1.
hiperparámetro
Una opción que un algoritmo no puede aprender de su propio objetivo, como k. Ver Sección 11.2.

I

imputar
Llenar un valor faltante con una estimación. Ver Sección 10.1.
index.qmd
La fuente de la página de inicio de un sitio web. Ver Sección 7.3.
indicador (de la terminal)
La línea que termina en $ (o en % en una Mac) y que muestra que la terminal está lista, y quién eres y dónde estás (en inglés, prompt). Ver Sección 3.3.
índice de Rand ajustado (ARI)
Un puntaje de cuánto coinciden dos agrupamientos más allá del azar: 1 significa idénticos, 0 no mejor que el azar. Ver Sección 11.2.
inercia
La suma de las distancias al cuadrado de cada punto al centro de su clúster. Ver Sección 11.1.
IPM
El Índice de Pobreza Multidimensional: la proporción de las personas de una zona que son pobres en varios aspectos a la vez, según el censo de 2018. Ver Sección 8.5.
IRCA
El Índice de Riesgo de la Calidad del Agua para consumo humano de Colombia, de 0, todas las pruebas aprobadas, a 100, todas reprobadas. Ver Sección 8.2.
IRCA de prestadores
El IRCA de las muestras de sistemas que opera un prestador del servicio de agua, que subestima el riesgo donde la gente se autoabastece. Ver Sección 8.2.

J

Jupyter
El motor de cálculo que ejecuta las celdas de código de Python (knitr hace lo mismo para R). Ver Sección 1.2.

K

k
Cuántos clústeres se le pide encontrar a k-means. Ver Sección 11.1.
kernel
El proceso de Python en ejecución que ejecuta las celdas de un documento, de arriba hacia abajo. Ver Sección 5.7.
k-means++
La forma en que scikit-learn elige centros iniciales dispersos, lo que hace menos probable un inicio atascado. Ver Sección 11.1.

L

línea en blanco
Una línea sin nada. En Markdown empieza un párrafo nuevo, y una lista necesita una antes. Ver Sección 4.1.
línea horizontal
Una línea que cruza la página, escrita como --- entre líneas en blanco. Ver Sección 4.1.
lista de tareas
Una lista con viñetas cuyos elementos empiezan con una casilla, [ ] vacía o [x] marcada. Ver Sección 4.1.
listado
Una página que enumera otras páginas, como cada entrada de un blog, hecha por Quarto. Ver Sección 14.4.
logaritmo
Una escala que mide razones y no diferencias: cada vez que algo se duplica, suma lo mismo. Ver Sección 10.1.

M

mapa coroplético
Un mapa cuyas áreas se colorean según un valor. Ver Sección 14.7.
Markdown
Una forma de escribir texto estructurado con unos pocos signos de puntuación, como # antes de un título. Ver Sección 1.2 y Sección 4.1.
Markdown de Pandoc
El Markdown que lee Quarto: las marcas básicas de GFM, más atributos entre llaves, notas al pie, listas de definiciones, citas bibliográficas y matemáticas. Ver Sección 4.1.
MDM
La Medición del Desempeño Municipal del DNP, un puntaje de la gestión y los resultados de un municipio, de 0 a 100. Ver Sección 8.5.
mediana
El valor del medio, con la mitad de los valores por debajo. Ver Sección 9.1.
modelo
Un modelo de lenguaje grande: lee y escribe texto, y puede responder con una solicitud para usar una herramienta. Ver Sección 2.1.
monótona
Una relación en la que una variable tiende a subir cuando la otra sube, aunque no necesariamente a lo largo de una línea recta. Ver Sección 13.1.
mortalidad infantil
Las muertes de menores de un año por cada 1,000 nacidos vivos. Ver Sección 8.5.
municipio-año
Un municipio en un año: la unidad de las variables de resultado municipales, la mortalidad infantil y la deserción. Ver Sección 12.4.

N

nano
El editor de texto simple de la propia terminal: Ctrl+O y Enter guardan, Ctrl+X sale. Ver Sección 4.5.
niveles de riesgo del IRCA
Los cinco rangos del IRCA de la Resolución 2115: sin riesgo, bajo, medio, alto e inviable sanitariamente. Ver Sección 8.2.
números pequeños
En los lugares pequeños, un puñado de muertes mueve mucho una tasa, así que las tasas extremas son frágiles. Ver Sección 12.4.

O

opciones de celda
Instrucciones para una celda de código en sus primeras líneas, escritas como comentarios que empiezan con #|. Ver Sección 5.1 y Sección 5.4.

P

Pandoc
El conversor de documentos dentro de Quarto que convierte el Markdown ejecutado en cada formato de salida. Ver Sección 1.2.
paquete
Una biblioteca adicional que importa el código de Python, como pandas para tablas o matplotlib para gráficos. Ver Sección 4.10.
Parquet
Un formato de archivo para tablas que conserva el tipo de cada columna, así que un código como 05001 sigue siendo texto. Ver Sección 8.6.
PATH
La lista de carpetas en las que una terminal busca programas, que se lee cuando la terminal arranca. Ver Sección 3.4.
percentil
El valor por debajo del cual queda una proporción dada de los valores; el 5 y el 95 delimitan el 90% central. Ver Sección 12.5.
perfil
La media de cada característica de un clúster sobre sus filas, en unidades z. Ver Sección 12.1.
pesos corrientes
Pesos no ajustados por inflación (pesos nominales). Ver Sección 10.1.
Pide, revisa, publica
El ciclo que enseña este libro: pídele a un agente un paso pequeño, revisa lo que hizo y deja que Quarto reconstruya cada salida desde la fuente revisada (en inglés, Prompt, Check, Publish). Ver Figura 1.
pre-render
Un script que Quarto ejecuta antes de cada renderizado de un proyecto, incluso de una sola página. Ver Sección 14.4.
programa de línea de comandos
Un programa que ejecutas escribiendo un comando en una terminal. Ver Sección 1.2.
prompt
La solicitud que le escribes al agente. Ver Sección 2.6.
proyecto de Quarto
Una carpeta que un archivo _quarto.yml en su parte de arriba convierte en un sitio web o un libro. Ver Sección 7.3.
pull request
Una propuesta para hacer merge de una rama, que muestra la diferencia línea por línea. Ver Sección 7.1.
puntaje z
La distancia de un valor a la media de su año, en desviaciones estándar; no tiene unidad. Ver Sección 10.1.
punto de control
Una carpeta de checkpoints/ del taller que contiene un proyecto tal como debería estar al final de un bloque práctico, con un README de pasos para ponerse al día. Ver Sección 4.11 y Figura 2.
push
Copiar commits al repositorio compartido en GitHub. Ver Sección 7.1.

Q

quarto preview
Renderiza un archivo, lo sirve en una dirección local y lo vuelve a renderizar cada vez que se guarda; Ctrl+C lo detiene. Ver Sección 4.1 y Sección 4.4.

R

rama
Una etiqueta móvil sobre una línea de commits. Ver Sección 7.1.
recuadro para ponerte al día
La línea que se pega en el agente donde el libro llega a un punto de control; después de ponerte al día, sigues leyendo desde el recuadro. Ver Sección 4.11 y Figura 2.
regla de nombres
Una regla escrita que le pone nombre a cada clúster a partir de su perfil: entorno, cobertura relativa y el nivel de la mediana de su IRCA. Ver Sección 12.2.
renderizar
Construir las salidas de un documento a partir de su fuente; quarto render ejecuta, convierte y compone. Ver Sección 1.2 y Sección 4.1.
repositorio
Una carpeta de proyecto con su historial de Git. Ver Sección 1.4.
reproducible
Otra persona, o tú más adelante, puede reconstruir los mismos resultados a partir de los mismos archivos con un solo comando, y ver de dónde salió cada número. Ver Sección 1.4.

S

Saber 11
El examen nacional del ICFES para los estudiantes que terminan la educación media, con un puntaje global de 0 a 500. Ver Sección 8.3.
salto de línea
Una línea nueva dentro de un párrafo, que se hace terminando la línea con una barra invertida. Ver Sección 4.1.
selección según la variable de resultado
Conservar o descartar filas según el valor que se está midiendo, así que las filas conservadas no son típicas. Ver Sección 12.4.
semilla aleatoria
El número que pone en marcha el generador de números aleatorios de la computadora, para que los inicios al azar sean iguales en cada ejecución. Ver Sección 11.1.
sesión principal
La sesión del agente que inicia los subagentes, los espera y revisa sus resultados. Ver Sección 6.2.
SGP
El Sistema General de Participaciones, las transferencias de la Nación a los municipios; la característica es su asignación para agua potable y saneamiento básico, por persona. Ver Sección 8.5.
shell
El programa detrás de la terminal que ejecuta tus comandos. Ver Sección 3.4.1.
silueta
Un puntaje de −1 a 1 de cuánto más cerca está cada punto de su propio clúster que del siguiente, promediado sobre los puntos. Ver Sección 11.2.
sistema de autoabastecimiento
Un sistema de agua que no opera ningún prestador. Ver Sección 8.2.
sitio estático
Una carpeta de HTML, CSS, JavaScript, imágenes y documentos, sin ningún programa corriendo en un servidor. Ver Sección 7.2.
SIVIGILA
El sistema de vigilancia en salud pública de Colombia. Ver Sección 14.8.
ρ de Spearman
Una medida, de −1 a +1 pasando por 0, de si dos variables suben y bajan juntas en orden de rango. Ver Sección 13.1.
subagente
Una sesión de agente separada que tu agente inicia para una tarea, con su propio contexto. Ver Sección 6.2.
sudo
Ejecuta un comando como administrador, después de pedir tu contraseña. Ver Sección 3.2.
SVG
Un dibujo escrito como texto, que un modelo escribe igual que escribe código. Ver Capítulo 2.

T

tachado
Texto cruzado por una línea, escrito entre dos virgulillas a cada lado, ~~Car~~. Ver Sección 4.1.
terminal
Una ventana en la que escribes comandos en lugar de hacer clic. Ver Sección 3.3.
texto alternativo
La descripción que anuncian los lectores de pantalla, y que aparece si una imagen no carga. Ver Sección 4.7.
token
Un fragmento de texto de unos pocos caracteres: la unidad que leen, escriben y cobran los modelos. Ver Sección 2.2.
trabajo de CI
Una construcción que un servicio como GitLab ejecuta en cada push. Ver Sección 7.2.
Typst
Un sistema de composición tipográfica moderno que viene dentro de Quarto y hace sus PDF. Ver Sección 1.2.

U

unir
Emparejar las filas de dos tablas por una columna que comparten (en inglés, join). Ver Sección 8.4.
uv
La herramienta que instala Python y administra los paquetes de cada proyecto. Ver Sección 3.5 y Sección 4.10.
uv run
Ejecuta un comando en el entorno del proyecto, después de poner .venv al día con uv.lock. Ver Sección 4.10.

V

variable de confusión
Una tercera variable que afecta tanto a la exposición como a la variable de resultado, así que las dos se mueven juntas aunque una no tenga ningún efecto sobre la otra. Ver Sección 13.2.
variable de resultado
Una variable que el análisis solo compara entre los tipos y que nunca usa para agrupar. Ver Sección 8.5.
variable de zona
Una variable que se mide por separado para las zonas urbana y rural de un municipio; una variable municipal tiene un solo valor para todo el municipio, repetido en las dos filas. Ver Sección 8.5.
varianza
El cuadrado de la desviación estándar. Ver Sección 10.3.

W

WebGL
Los gráficos 3-D integrados en el navegador. Ver Sección 6.5.
WSL
El Subsistema de Windows para Linux, que ejecuta Ubuntu dentro de Windows. Ver Capítulo 3.

Y

YAML
Un formato de configuración en el que la sangría tiene significado. Ver Sección 1.2 y Sección 5.1.

Z

zona rural
Los centros poblados más pequeños y el campo disperso de un municipio. Ver Sección 8.4.
zona urbana
La cabecera municipal de un municipio. Ver Sección 8.4.
zona-año
La zona urbana o rural de un municipio en un año: una fila de los datos del agua, y la unidad de análisis de la Parte III. Ver Sección 8.4.
